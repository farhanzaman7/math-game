# Math Game

A simple addition game for kids ages 5–8.

## Features
- Single page: index.html with inline CSS and JS, no frameworks
- Shows one addition question at a time
- Difficulty picker: Easy (0–5), Medium (0–10), Hard (0–20)
- Big input box (number keyboard on mobile) and a "Check" button; Enter key also submits
- Correct: cheerful message, then next question after ~1 second
- Wrong: gentle "try again" message, same question stays
- Score counter at the bottom showing correct answers out of total submitted
- Large fonts, bright kid-friendly colors, works on phone and laptop

## Out of scope (for now)
Timers, sounds, other operations
